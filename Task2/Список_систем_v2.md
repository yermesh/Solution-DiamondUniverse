СПИСОК СИСТЕМ



Внутренняя, основной бизнес



ИС "Алмазы" ( текущая )

Текущие процессы

* Планирование работ.
* Присвоение идентификаторов.
* Подготовка ведомостей.

Новые процессы

* Отбор алмазов для будущего цифрового аукциона.



ИС "Аукцион" ( текущая ) : Проведение аукциона ( оффлайн ).

Текущие процессы

* Оффлайн-аукцион.

Новые процессы

* Онлайн-аукционов.
* Внесение данных от Лаборатории в БД ( ручной в Предварительном, и автоматический в Целевои решении ).
* Публикации данных о лотах алмазов для клиентов.



Внутренняя, обеспечение операций



ИС "Логистика" ( текущая )

Текущие процессы

* Отправка алмазов в Офис.
* Отпрака алмазов Клиентам.

Новые процессы

* Отправка алмазов в Лабораторию, и возврат в офис после оцифровки.



ИС "Бухгалтерия" ( текущая )

Текущие процессы

* Управление контрактами.
* Актирование услуг Логистики.
* Оплата услуг логистики.

Новые процессы

* Актирование услук Лоборатории ( ручной в Предварительном, и автоматический в Целевои решении ).
* Оплата услуг лабораторий ( ручной в Предварительном, и автоматический в Целевои решении ).



ИС "FIREWALL" ( новая )

Новые процессы

* Фильтрация трафика

  * Передаваемых данных запросов.
  * Передаваемых файлов.
  * Подключеных Клиентов Онлайн-аукциона.



Внешная, обеспечение операций



ИС "Лаборатория" ( новая )

Новые процессы

* Оценка и оцифровка алмазов.
* Управление заказами.

Риски

* Внешняя система подрядчика - зависимость от контракта с ним.



ИС "Облачный сервис" ( новая )

Новые процессы

* Хранение реестра оцифрованных алмазов.
* Хранение Актов об услугах Лаборатории для Бухгалтерии.
* Хранение Запросов на оплату услугах Лаборатории.

Риски

* Зависимость от доступности Интернета и качества канала связи.
* Зависимость от подписки на облачный сервис.
* Есть риск утечки конфиденциальных данных.


ИС "Excel" ( новая ) - для ИС "Лаборатория" ( для Предварительного решения )

Новые процессы ( ручные )

* Составление Реестра оцифрованных алмазов.
* Составление Актов об услугах Лаборатории.
* Составление Запросов на оплату услуг Лаборатории.

Риски

* Файлы долго заполнять и обрабатывать вручную.
* Файлы могут быть повреждены или утеряны.
* Есть риск утечки конфиденциальных данных.



СПИСОК ИНТЕГРАЦИЙ



ИС "Алмазы" >> ИС "Логистика" ( текущая )

Текущие

* REST - Запрос на Логистику алмазов в Офис.
* REST - Запрос на Логистику алмазов в Клиентам.

Новые

* Запрос на Логистику алмазов в Лобораторию, и в офис после оцифровки.

  * Промежуточно : REST ( 2 месяца ).
  * Итого: REST ( 1 год ) - без изменений.



ИС "Логистика" >> ИС "Бухгалтерия" ( текущая )

Текущие

* REST - Актирование услуг Логистики в Офис.
* REST - Запрос на оплату услуг Логистики в Офис.
* REST - Актирование услуг Логистики к Клиентам.
* REST - Запрос на оплату услуг Логистики к Клиентам.

Новые

* Актирование услуг Логистики в Лабораторию, и после в Офис.

  * Промежуточно : REST ( 2 месяца ).
  * Итого: REST ( 1 год ) - без изменений.
* Запрос на оплату услуг Логистики в Лабораторию, и после в Офис.

  * Промежуточно : REST ( 2 месяца ).
  * Итого: REST ( 1 год ) - без изменений.



ИС "Лаборатория" >> ИС "Аукцион" ( новая )

Новые

* Передача описания оцифрованных алмазов.

  * Промежуточно : Ручной ( 2 месяца ) excel-файл через Облако.
  * Итогово: REST ( 1 год ).



ИС "Лаборатория" >> ИС "Бухгалтерия" ( новая )

Новые

* Актирование услуг Лаборатории.

  * Промежуточно : Ручной ( 2 месяца ) - excel-файл через Облако.
  * Итого: REST ( 1 год ).
* Запрос на оплату услуг Лаборатории.

  * Промежуточно : Ручной ( 2 месяца ) - excel-файл через Облако.
  * Итого: REST ( 1 год ).



ИС "Аукцион" >> ИС "STORAGE" ( новая )

Новые

* Внесение данных об оцифрованных алмазов в БД.

  * Промежуточно : Ручной ( 2 месяца ) после получения excel-файла от Лаборатории.
  * Итогово: INSERT ( 1 год ) после получения через REST.
* Предоставление данных об алмазах ( медиа, описание ) для Web-портала аукциона.

  * Промежуточно : SELECT ( 2 месяца ).
  * Итого: SELECT ( 1 год ) - без изменений.
