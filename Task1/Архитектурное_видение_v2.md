ЗАДАЧА
Разработка нового бизнес-процесса онлайн-аукциона для компании "Diamond Universe" ( занимающейся разработкой месторождений и продажей алмазов ) с целью увеличения продаж алмазов, и должен включать следующие шаги :

* Отбор алмазов для продажи онлайн.
* Перевозка алмазов в лабораторию, их оцифровка, и возврат обратно в офис.
* Публикация данных для покупателей, на основе которых будут приниматься решения.
* Проведение онлайн-аукциона.
* Отправка камней победителям торгов из офиса.
* Финансовое и бухгалтерское сопровождение аукциона.



КОНТЕКСТ
В настоящее время аукцион по продаже алмазов проводиться в офлайн-формате в офисе компании, что :

* Ограничивает количество участников в офисе аукциона, в частности, в связи с ограничениями по причине пандемии COVID-19.
* Есть зависимость от конкретных лиц.
* Нет полной автоматизации операций.
* Не все системы интегрированы между собой.



ОПИСАНИЕ ПРОМЕЖУТОЧНОГО РЕШЕНИЯ

Разработать ( через 2 месяца ) Промежуточное решение, которое будет включать в себя :

* Интернет-Портал для клиентов для участия клиентов онлайн ( через HTTPS ), с поддержкой языков :

  * Английский.
  * Русский.
* Обмен данными об оцифрованных алмазах между новой ИС "Лаборотория" и ИС "Аукцион" в формате excel через Облачное хранилице.

  * Временно, до перехода на Целевое решение.
* БД для хранения данных об оцифрованных алмазах, полученных через excel-файлал от Лаборатории ( через Облако ).

  * Внос данных вручную - Временно, до перехода на Целевое решение.
* Обмен данными о запросах на оплату услуг между ИС "Лаборотория" и ИС "Бухгалтерия" в формате excel через Облачное хранилице.

  * Временно, до перехода на Целевое решение.
* Интеграции между системами ( ШИНУ ), обеспечивающими работу аукциона.

  * Добавить в текущую интеграцию ИС "Алмазы" >> ИС "Логистика" - Заказ на логистику до Лабораторию.
  * Добавить в текущую интеграцию ИС "Логистика" >> ИС "Бахгалтерия" - Акты и Запрос на логистику до Лабораторию.
* Некоторые сервисы могут быть размещены в облаке ( excel-файлы ).

  * Временно, до перехода на Целевое решение.
* Защита конфиденциальных данных через Firewall.


ОПИСАНИЕ ЦЕОЕВОГО РЕШЕНИЯ

Разработать ( через год ) Итоговое решение, которое будет включать в себя :

* Интернет-Портал для клиентов для участия клиентов онлайн ( через HTTPS ), с поддержкой языков :

  * Английский.
  * Русский.
  * Испанский.
  * Китайский.
  * Арабский.
* БД для хранения данных об оцифрованных алмазах, полученных через REST от Лаборатории.

  * Внос данных автоматически через REST ( интеграциюнную шину ) после получения.
* Автоматизация операций по обеспечения работы онлайн-аукциона.

  * Продажи.
  * Отслеживание и актуализация статусов заявок.
  * Отбор и оцифровка алмазов для аукциона.
  * Учетные, Финансовые, Контрактные, Платежные операции.
  * Логистические операции.
* Интеграции между системами ( через ШИНУ ), обеспечивающими работу аукциона.

  * Отказ от обмена файлами через облако из Промежуточного решения.
* Защита конфиденциальных данных через Firewall.
