"Задача"
Разработка нового бизнес-процесса онлайн-аукциона для компании "Diamond Universe" ( занимающейся разработкой месторождений и продажей алмазов ) с целью увеличения продаж алмазов, и должен включать следующие шаги :
- Отбор алмазов для продажи онлайн.
- Перевозка алмазов в лабораторию, их оцифровка, и возврат обратно в офис.
- Публикация данных для покупателей, на основе которых будут приниматься решения.
- Проведение онлайн-аукциона.
- Отправка камней победителям торгов из офиса.
- Финансовое и бухгалтерское сопровождение аукциона.

"Контекст"
В настоящее время аукцион по продаже алмазов проводиться в офлайн-формате в офисе компании, что :
- Ограничивает количество участников в офисе аукциона, в частности, в связи с ограничениями по причине пандемии COVID-19.
- Есть зависимость от конкретных лиц.
- Нет полной автоматизации операций.
- Не все системы интегрированы между собой.

"Описание оптимального решения"
Разработать в течении 2 месяцев итоговое решение, которое будет включать в себя :
- Интернет-Портал для клиентов для участия клиентов онлайн.
- Автоматизация операций по обеспечения работы онлайн-аукциона.
  - Продажи.
  - Отслеживание и актуализация статусов заявок.
  - Отбор и оцифровка алмазов для аукциона.
  - Учетные, Финансовые, Контрактные, Платежные операции.
  - Логистические операции.
- Интеграции между системами, обеспечивающими работу аукциона.
- Некоторые сервисы могут быть размещены в облаке.
- Защита конфиденциальных данных.
